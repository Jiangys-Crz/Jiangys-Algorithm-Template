\chapter{图论}

设图有 $n$ 个顶点、$m$ 条原边，分别从 $1$ 和 $0$ 编号。

\texttt{Graph(n)} 构造有向图，\texttt{Graph(n,false)} 构造无向图。

边权类型为 \texttt{ll}。

\section{图的基础}

\subsection{图的存储}

邻接表按顶点组织出弧，边表按加入顺序保存原边。邻接矩阵可按端点直接访问。

\begin{itemize}
    \item \texttt{edges[id]} 保存端点和权值，\texttt{adj[u]} 保存从 $u$ 可走的弧及原边编号。
    \item 无向边在边表中只存一次，在两个端点的邻接表中都存入同一个边编号。
\end{itemize}

\texttt{addEdge(u, v, w)} 返回原边编号。无权图省略 $w$，表示边长为 $1$。

\cppfile{code/graph/graph.hpp}

\paragraph{复杂度}
边表和邻接表的构建时间与空间均为 $O(n+m)$，单次插边均摊为 $O(1)$。邻接矩阵占 $O(n^2)$ 空间。

自环、重边是否允许由具体算法决定。矩阵若要表示重边，须先明确合并规则，例如最短路取最小权。

\subsection{DFS、BFS 遍历}

DFS 沿当前分支深入后回退。BFS 从起点开始逐层访问，在无权图上，层号就是最少经过的边数。

\begin{itemize}
    \item 迭代 DFS 的栈帧记录节点及下一条待处理的边，可以得到与递归 DFS 相同的访问次序。
    \item BFS 发现新节点时立即设置距离并入队，同一节点只入队一次。
\end{itemize}

从 $s$ 出发，\texttt{order} 保存 DFS 序，\texttt{dist} 保存无权最短距离，不可达时为 $-1$。

\cppfile{code/graph/图的遍历.cpp}

\paragraph{复杂度}
扫描所有节点和边时，时间为 $O(n+m)$，额外空间为 $O(n)$。

图中可能有环或多条路径到同一点，需要用访问状态去重。

\subsection{连通分量}

无向图的连通分量是两两可达的极大顶点集。每次从一个未编号顶点出发，标记其所属分量。

\begin{itemize}
    \item 外层扫描所有点。每遇到一个尚未编号的点，把分量编号 $\mathrm{cnt}$ 加一。
    \item 从该点访问所有可达点，并在第一次发现时填入同一个编号。
\end{itemize}

\texttt{cnt} 为分量数，\texttt{bel[u]} 为 $u$ 所属的连通分量，编号从 $1$ 开始。

\cppfile{code/graph/连通分量.cpp}

\paragraph{复杂度}
时间为 $O(n+m)$，额外空间为 $O(n)$。

有向图的互相可达需要求强连通分量。若只需弱连通分量，可以对忽略方向后的图应用此模板。

\subsection{拓扑排序}

拓扑序中，每条有向边的起点先于终点。有向图有拓扑序当且仅当它无环。

\begin{itemize}
    \item 将入度为零的点入队。每次出队后逐条扣除其出边对应的入度，包括重边。
    \item 将入度降为零的点入队。若最终仍有未出队的点，则图有环。
\end{itemize}

\paragraph{Kahn 算法}

\texttt{acyclic} 为真时，\texttt{order} 是有向图的拓扑序。

\cppfile{code/graph/toposort.cpp}

\paragraph{复杂度}
时间为 $O(n+m)$，额外空间为 $O(n)$。

\subsection{DAG 动态规划}

按拓扑序处理顶点，使每个状态先收齐所有前驱的贡献，再向后继转移。状态可以表示距离、路径数或其他累积信息。初值、不可达状态与合并运算由目标确定。

若每条边只做常数次转移，拓扑排序与状态更新合计耗时 $O(n+m)$。

\subsection{图的判环}

\begin{itemize}
    \item 有向图若拓扑排序不能取出全部节点，则有环。用 DFS 时，也可检测是否有边指向当前递归栈中的节点。
    \item 无向图若一条新边连接了已经连通的两个点，这条新边与已有路径形成环。
\end{itemize}

\paragraph{并查集}

\texttt{merge(u,v)} 在合并两个不同分量时返回真。

\cppfile{code/graph/graph_dsu.hpp}

\paragraph{分别检查有向图和无向图}

无向图的自环视为一条环，两条平行边也可以构成环。

\cppfile{code/graph/图的判环.cpp}

\paragraph{复杂度}
有向图耗时 $O(n+m)$。无向图使用按大小合并和路径压缩，耗时 $O(n+m\alpha(n))$。额外空间均为 $O(n)$。

\subsection{二分图判定}

二分图可以将节点染成两种颜色，每条边的两个端点颜色都不同。无向图是二分图，当且仅当它没有奇环。

\begin{itemize}
    \item 从每个未染色点开始 BFS，相邻节点染成相反的颜色。
    \item 若遇到颜色相同的边，其两端间已确定的奇偶性互相矛盾。
\end{itemize}

\texttt{bipartite} 为真时，\texttt{color} 保存无向图的一组合法染色。

\cppfile{code/graph/二分图判定.cpp}

\paragraph{复杂度}
时间为 $O(n+m)$，额外空间为 $O(n)$。

自环使二分图染色无解。

\subsection{图的建模、分层图}

若可选操作取决于已使用的资源或当前阶段，可将这些信息与原顶点一起作为状态。每个状态对应新图中的一个顶点，每种合法操作对应一条边。

层内边保留资源使用量，跨层边更新资源或阶段。起点由初始状态确定，终点取满足限制的状态集合。使用最短路时，算法与复杂度由新图的边权和规模决定。

\section{最短路}

\subsection{Dijkstra}

当边权均非负时，可以用小根堆优先处理当前距离最小的状态。从堆中取出该节点的有效状态时，它的最短距离已经确定。

\begin{itemize}
    \item 初始化源点距离为 $0$，随后用 $d[u]+w$ 尝试减小 $d[v]$。
    \item 标准库优先队列无法直接减少已有项的键，模板插入新状态并在弹出时丢弃旧状态。
\end{itemize}

\texttt{sources} 保存源点，单源时只含一个顶点。\texttt{dist} 保存最短距离，不可达时为 \texttt{inf}。有限最短距离须小于 \texttt{inf}。

\cppfile{code/graph/dijkstra.cpp}

\paragraph{复杂度}
设输入源点序列的长度为 $s$。时间为 $O(s+(n+m)\log(n+m+1))$，额外空间为 $O(n+m)$。

\subsection{Bellman-Ford}

Bellman-Ford 反复扫描所有边进行松弛，允许负边。在没有可达负环时，最短路可以取成不重复顶点的简单路径。

\begin{itemize}
    \item 只有 $u$ 可达时才能用 $d[u]+w$ 更新 $d[v]$。一次完整扫描没有更新即可停止。
    \item 简单路径最多有 $n-1$ 条边。第 $n$ 轮仍有更新时，存在源点可达的负环。
\end{itemize}

\texttt{negativeCycle} 为真时，\texttt{dist} 保存检测到负环时的暂存距离；受负环影响的顶点没有有限最短距离。
松弛和返回距离均使用 \texttt{lll}，不可达顶点为 \texttt{graph\_detail::wideInf}。

\cppfile{code/graph/bellman_ford.hpp}

\paragraph{复杂度}
每轮扫描 $O(m)$ 条边，最坏 $O(n+nm)$ 时间，额外空间 $O(n)$。

单源版只检测源点可达的负环。若须检查整张图，可加一个向所有点连零边的超级源点。

\subsection{SPFA}

SPFA 使用队列减少 Bellman-Ford 的部分无效扫描。某点距离变小后，把它加入队列，以传播新的距离。

\begin{itemize}
    \item 出队时扫描出边。已经在队列中的节点继续使用最新距离，避免重复入队。
    \item 每次成功松弛记录新路径的边数 $\mathrm{len}[v]=\mathrm{len}[u]+1$。达到 $n$ 时报告可达负环。
\end{itemize}

返回类型与 Bellman-Ford 相同。

\cppfile{code/graph/SPFA.cpp}

\paragraph{复杂度}
最坏时间为 $O(n+nm)$，额外空间为 $O(n)$。

\subsection{Floyd-Warshall}

$d[u][v]$ 表示仅允许使用已处理的中间顶点时，$u$ 到 $v$ 的最短距离。

\begin{itemize}
    \item 用 $d[u][u]=0$ 和直接边初始化。平行边取最小权。
    \item 以 $k$ 为最外层循环，令 $d[u][v]\gets\min(d[u][v],d[u][k]+d[k][v])$。
    \item 若 $d[k][k]<0$，则存在从 $k$ 出发并返回 $k$ 的负权闭合游走。对于能到达 $k$ 的 $u$ 和从 $k$ 可达的 $v$，$u$ 到 $v$ 的距离无有限下界。
\end{itemize}

\texttt{edges} 存放有向带权边，\texttt{dist} 用 \texttt{lll} 保存距离矩阵，不可达时为 \texttt{inf}。
低于 $-\mathrm{inf}$ 的松弛结果截断至 $-\mathrm{inf}$，以限制负环反复松弛时的数值范围。

\cppfile{code/graph/Floyd.cpp}

\paragraph{复杂度}
时间为 $O(n^3)$，空间为 $O(n^2)$。

\subsection{0-1 BFS}

边权只有 $0$ 和 $1$ 时，处理距离 $d$ 的节点只会产生距离 $d$ 或 $d+1$ 的新状态，可以用双端队列维护顺序。

\begin{itemize}
    \item 通过零边松弛成功时压到队首，通过一边松弛成功时压到队尾。
    \item 出队时跳过不再等于当前最短距离的状态。
\end{itemize}

从 $s$ 出发，\texttt{dist} 保存最短距离，不可达时为 \texttt{inf}。

\cppfile{code/graph/01BFS.cpp}

\paragraph{复杂度}
时间为 $O(n+m)$，额外空间为 $O(n+m)$。

已入队顶点的距离仍可能被零权边改善。

\subsection{多源最短路}

多源最短路求从源点集合到各顶点的最短距离。将各源点的距离置零，等价于从超级源点连零权弧。
无权图用 BFS，零一边权图用 0-1 BFS，非负权图可用 Dijkstra。

使用本节 Dijkstra 示例的源点初始化循环。有负权边时，可增设超级源点并使用 Bellman-Ford。

\paragraph{复杂度}
直接初始化时，开销为一次单源算法加上对源点数组的一次扫描。显式建图时还需计入所增顶点与边。

有向图上若求各顶点到源点集合的距离，需在反图上计算多源最短路。

\subsection{最短路计数}

先算出最短距离，再沿满足最短路等式的边累加方案数。边权严格为正时，每次转移的距离都严格增加。

\begin{itemize}
    \item 只使用满足 $d[u]+w(u,v)=d[v]$ 的边，按 $d[u]$ 的递增顺序做 DP。
    \item 令源点方案数为 $1$，对每条合法边把 $\mathrm{ways}[u]$ 加到 $\mathrm{ways}[v]$。
\end{itemize}

对参数 \texttt{mod} 取模，模数须为正，默认取 $10^9+7$。平行边按不同的路径计数。源点的空路径计为一个方案。

\cppfile{code/graph/最短路计数.cpp}

\paragraph{复杂度}
Dijkstra 后额外排序 $O(n\log n)$，再扫描 $O(n+m)$，总时间为 $O((n+m)\log(n+m))$。

零权边可连接等距离顶点。最短路子图无环时，可按拓扑序计数。
最短路径上若可反复经过零权环，则最短游走可有无限多条。

\subsection{差分约束}

形如 $x_u-x_v\le w$ 的约束可以表示为一条 $v\to u$ 的有向边，权值为 $w$。所有约束要求变量满足这些边上的松弛不等式。

\begin{itemize}
    \item 从超级源点向每个变量连零边，让所有顶点可达。
    \item 若存在负环，把环上的各条不等式相加会得到矛盾。否则每个变量取其最短距离，就是一组可行解。
\end{itemize}

\texttt{add(u,v,w)} 表示 $x_u-x_v\le w$。\texttt{work()} 返回用 \texttt{lll} 保存的可行解，无解时返回空值。

\cppfile{code/graph/差分约束.cpp}

\paragraph{复杂度}
设 $m$ 为约束条数，增加 $n$ 条超级源点边后，最坏耗时 $O(n(n+m))$，空间为 $O(n+m)$。

约束方向易写反。下界 $x_u-x_v\ge w$ 应先变形成 $x_v-x_u\le -w$。

\section{最小生成树}

\subsection{Kruskal}

最小生成树在连通无向图中选取总权最小的生成树。Kruskal 按边权从小到大扫描，每次选取能连接两个不同分量的边。

\begin{itemize}
    \item 用并查集维护当前森林。成功合并时记录这条原边，并增加总权。
    \item 接纳 $n-1$ 条边时已经生成整棵树。边耗尽仍不足 $n-1$ 条时图不连通。
\end{itemize}

支持负边和重边。无生成树时返回空值，单点图返回总权为 $0$ 的空树。

\cppfile{code/graph/kruskal.hpp}

\paragraph{复杂度}
排序耗时 $O(m\log m)$，并查集操作耗时 $O(n+m\alpha(n))$。额外空间为 $O(n+m)$。

无向图的原始边表中每条边只出现一次。选边时用是否合并成功判断，自环会被跳过。

\subsection{Prim}

Prim 从给定起点开始，每次用当前已经加入的点到外部点的最轻边扩张，始终维护一棵连通的部分生成树。

\begin{itemize}
    \item 每加入一个点，把它连向未加入点的边压入小根堆。
    \item 出堆时若目标点已加入就跳过。否则接纳所取边，再继续扩张。
\end{itemize}

支持从任意顶点开始。返回类型与 Kruskal 相同。

\cppfile{code/graph/Prim.cpp}

\paragraph{复杂度}
堆实现耗时 $O(n+m\log(2+m))$，额外空间为 $O(n+m)$。稠密图可用扫描版本，耗时 $O(n^2)$。

堆中键是连接新点的单条边权。负边也合法，更新规则与累加路径距离的 Dijkstra 不同。

\subsection{次小生成树}

严格次小生成树的总权必须大于最小生成树。先固定一棵最小生成树，考虑加入一条非树边并从形成的环中换掉一条树边。

\begin{itemize}
    \item 设待加入的非树边权为 $w$。为使总权严格增加且增量最小，应删掉两端路径上小于 $w$ 的最大边权。
    \item 路径最大边权等于 $w$ 时，改用严格小于最大值的次大边权。用倍增维护每段路径的两个不同最大值。
    \item 严格次优的最小增量可以通过一次这样的换边取得。枚举所有非树边，再从合法候选中取最小总权。
\end{itemize}

\paragraph{查询带权树路径上最大的两个不同边权}

\texttt{TreePathMax} 接收一棵带权无向树。查询结果的 \texttt{first} 和 \texttt{second}
分别为最大、严格次大边权。对应值不存在时，该字段为空值。

\cppfile{code/graph/path_max.hpp}

\paragraph{求严格次小生成树总权}

输入无向图，允许平行边。图不连通或不存在严格次小生成树时返回空值。
最小和严格次小生成树的总权须能用 \texttt{ll} 表示，中间和及换边增量用 \texttt{lll} 计算。

\cppfile{code/graph/次小生成树.cpp}

\paragraph{复杂度}
时间为 $O(m\log m+(n+m)\log n)$，额外空间为 $O(m+n\log n)$。

若求的是与选定最小生成树边集不同的第二棵树，可允许等权交换。严格次大值必须与最大值不同。

\subsection{最小生成树相关性质}

\begin{itemize}
    \item 割性质表明，任一非平凡割的一条最轻跨割边属于某棵最小生成树。若该最轻边唯一，则它属于每棵最小生成树。
    \item 根据环性质，环中唯一最重的边不属于任何最小生成树。
    \item 根据瓶颈性质，最小生成树上 $u,v$ 间路径的最大边权等于原图中两点间的最小瓶颈值。
\end{itemize}

查询两个不同点之间的最小瓶颈值时，先用 Kruskal 建树，
再读取 \texttt{TreePathMax::query(u,v)} 的 \texttt{first}。

\paragraph{复杂度}
建树后倍增预处理为 $O(n\log n)$，单次瓶颈查询为 $O(\log n)$。

\section{图的连通性}

\subsection{Tarjan 强连通分量（SCC）}

强连通分量是有向图中两两互相可达的极大点集。Tarjan 用 DFS 序和一份尚未归属任何分量的栈识别分量边界。

\begin{itemize}
    \item 进入 $u$ 时设 $\mathrm{dfn}[u]=\mathrm{low}[u]$，并压入候选栈。递归返回时用孩子的 $\mathrm{low}$ 更新父节点。
    \item 处理指向仍在候选栈中的节点 $v$ 的非树边时，用 $\mathrm{dfn}[v]$ 更新 $\mathrm{low}[u]$。
    \item 若 $\mathrm{low}[u]=\mathrm{dfn}[u]$，从候选栈弹到 $u$，得到一个分量。
\end{itemize}

\texttt{bel[u]} 为从 $1$ 开始的分量编号，\texttt{cnt} 是分量数。分量按弹栈顺序编号，缩点后每条跨分量边都从大编号指向小编号。

\cppfile{code/graph/scc.hpp}

\paragraph{复杂度}
时间为 $O(n+m)$，额外空间为 $O(n)$。

调用栈与候选栈有不同职责。已经分配分量的点不能再降低另一个点的 Lowlink。

\subsection{强连通分量缩点}

把每个 SCC 压成一个点，保留分量之间的边。缩点图一定是 DAG，因为不同分量形成有向环时，它们仍可互相到达。

\begin{itemize}
    \item 对原边 $u\to v$，若分量不同就建立 $\mathrm{bel}[u]\to\mathrm{bel}[v]$。
    \item 按源分量扫描所有成员，用目标分量上的时间戳去掉重复边。
    \item 若题目允许在分量内自由收集点权，可先按题意合并分量权值，再在 DAG 上做 DP。
\end{itemize}

先用同一个 \texttt{Graph} 求 SCC，再传入缩点函数。

\cppfile{code/graph/强连通分量缩点.cpp}

\paragraph{复杂度}
含 SCC 在内的总时间为 $O(n+m)$，额外空间为 $O(n+m)$。

本模板保留分量间可达关系。若还需要跨分量边的权值或重数，须按题意合并这些信息。

\subsection{割点}

无向图删去一个点及其相邻边后，如果连通分量数量增加，该点就是割点。

\begin{itemize}
    \item 非根 $u$ 存在 DFS 孩子 $v$ 满足 $\mathrm{low}[v]\ge\mathrm{dfn}[u]$ 时，删掉 $u$ 会使这棵子树与祖先一侧分离。
    \item DFS 根是割点，当且仅当它有至少两个 DFS 树孩子。
    \item 割点、桥和点双共用一次无向 Lowlink 遍历。
\end{itemize}

\paragraph{同时求割点、桥与点双连通分量}

输入无自环的无向图，支持平行边和多个连通分量。\texttt{cut[u]} 表示割点。

\cppfile{code/graph/undirected_lowlink.hpp}

\paragraph{复杂度}
时间和额外空间均为 $O(n+m)$。

根的孩子数按 DFS 树边计算，不能用原图中的度数代替。

\subsection{桥}

删去一条无向边后，若连通分量数量增加，这条边是桥。桥只能是 DFS 树边。

\begin{itemize}
    \item 对 DFS 树边 $(u,v)$，$v$ 为孩子，若 $\mathrm{low}[v]>\mathrm{dfn}[u]$，子树没有其他边通向 $u$ 或其祖先。
    \item 两条平行边可以互为绕行路径，沿一条边进入孩子时，只跳过同一边编号。
\end{itemize}

从 \texttt{UndirectedLowlink} 读 \texttt{bridge[id]}，编号与原图边表一致。

\paragraph{复杂度}
一次 $O(n+m)$ 的预处理后，查询一条边是否为桥是 $O(1)$。

这里是严格大于。$\mathrm{low}[v]=\mathrm{dfn}[u]$ 时仍有另一条路返回 $u$。

\subsection{边双连通分量}

删去所有桥后得到的连通块就是边双连通分量。每个点恰属于一个块，桥连接两个不同的块。

\begin{itemize}
    \item 先用无向 Lowlink 标出所有桥。
    \item 再次遍历无向图，跳过桥并给每个块编号。缩去块内细节后，桥在各原连通分量中构成一棵树。
\end{itemize}

读入原图和对应的 Lowlink 结果，返回从 $1$ 开始的分量编号。

\cppfile{code/graph/边双连通分量.cpp}

\paragraph{复杂度}
时间为 $O(n+m)$，给定 Lowlink 后额外空间为 $O(n)$。

桥的标记要对应原边编号。图本身可能不连通，桥组成的缩点图此时是一片森林。

\subsection{点双连通分量}

点双连通分量描述无向图中的块结构。割点可能处于多个块中，普通节点只属于一个块。

\begin{itemize}
    \item 将 DFS 树边以及由后代指向祖先的边放入边栈。
    \item 孩子 $v$ 返回且 $\mathrm{low}[v]\ge\mathrm{dfn}[u]$ 时，弹出直到 $(u,v)$ 为止的边，用这些边的不同端点构成一个块。
    \item 单独把孤立点视为一个块，桥对应一个含两个点的块。
\end{itemize}

\texttt{UndirectedLowlink::blocks} 返回每个块的顶点表。需要圆方树时，为每个块建立方点，再向块内每个原顶点连边。

\paragraph{复杂度}
记录所有块的总时间和空间均为 $O(n+m)$。

\subsection{2-SAT}

2-SAT 的每条限制是两个布尔文字的析取。为每个变量建立真和假两个节点，用蕴含关系把限制转成有向边。

\begin{itemize}
    \item 子句 $a\lor b$ 对应 $\neg a\to b$ 和 $\neg b\to a$。
    \item 若同一变量的真假两个文字在同一个 SCC，就会相互强制，问题无解。
    \item 本章按缩点图的逆拓扑序为 SCC 编号。对每个变量，令分量编号较小的文字为真。
\end{itemize}

\texttt{addClause(x,a,y,b)} 要求 $x=a$ 或 $y=b$ 至少一个成立。可以重复传入同一个文字来强制赋值。

\cppfile{code/graph/2SAT.cpp}

\paragraph{复杂度}
若有 $n$ 个变量和 $m$ 条子句，时间和空间均为 $O(n+m)$。

\section{图匹配与网络流}

\subsection{二分图最大匹配}

匹配是一组互不共享端点的边。二分图最大匹配的目标是最大化匹配边数。

\begin{itemize}
    \item 增广路从未匹配的左点出发，在未匹配边和已匹配边之间交替，走到未匹配的右点。翻转路径上的匹配状态可多匹配一对。
    \item 建流图时，从超级源向各左点、从各右点向超级汇连容量为一的边。每条二分图边从左向右连容量为一的边。
    \item 整数最大流中，从左向右流量为一的边构成最大匹配。
\end{itemize}

\paragraph{复杂度}
建网需 $O(n+m)$ 时间及空间，$n$ 为两侧点数之和。使用 Dinic 在这一单位网络上的时间为 $O((n+m)\sqrt n)$。

若左右侧都从 1 开始编号，建流图时须为右侧加偏移，使两侧占用不同的顶点。

\subsection{匈牙利算法}

竞赛中常把基于 DFS 寻找增广路的二分图最大匹配算法称为匈牙利算法，也称 Kuhn 算法。固定一个左点后，尝试给它找到一个右点。

\begin{itemize}
    \item 右点未匹配时直接配对。若已匹配，递归尝试让它原来的左点改配其他右点。
    \item 一次搜索内每个右点至多访问一次。新左点开始搜索时使用新时间戳。
\end{itemize}

两侧都分别从 $1$ 开始编号。\texttt{work()} 返回匹配数，\texttt{match[v]} 是右点 $v$ 匹配的左点，$0$ 表示未匹配。

\cppfile{code/graph/bipartite_matching.hpp}

\paragraph{复杂度}
设左、右点数为 $n_L,n_R$。最坏时间为 $O(n_L+n_R+n_Lm)$，空间为 $O(n_L+n_R+m)$。

本模板优化配对数量。带权指派可使用 KM、带权匈牙利算法或费用流，须按题目权值模型选择。

\subsection{最大流（Dinic）}

在容量网络中，最大流要求在满足边容量和中间点流量守恒的条件下，尽量多地从源点送到汇点。

\begin{itemize}
    \item 每条输入边配一条初始容量为零的反向边。推过正向边的流可以沿反向边撤回。
    \item BFS 建立残量图的层次。DFS 只沿距离增加一的边增广，直到当前层次图上无法再增广。
    \item 当前弧下标记住已经尝试的边。成对存边后，反边编号为 \texttt{id\char94 1}。
\end{itemize}

\texttt{Flow<ll>} 的顶点编号从 $1$ 开始，容量为非负数。

\texttt{maxFlow(s,t)} 更新残量容量并返回本次新增的流量。总流量须落在容量类型的表示范围内。

\cppfile{code/graph/dinic.hpp}

\paragraph{复杂度}
设输入有 $m$ 条边。一般网络的时间上界为 $O(n+n^2m)$，额外空间为 $O(n+m)$。

原网络中的反向弧应作为独立的输入边加入。DFS 的递归深度最坏为 $O(n)$。

\subsection{最小割}

源汇割把点分成包含源点的集合和包含汇点的集合。割容量是原网中所有从源侧指向汇侧的边容量之和。最大流量等于最小割容量。

\begin{itemize}
    \item 最大流结束后，从源点仅沿正残量容量的边标记可达区域。
    \item 可达点作为割的源侧，其余点作为汇侧。原图中从源侧到汇侧的边构成一个最小割。
    \item 跨割的原边都已饱和。此时割容量等于当前流量。
\end{itemize}

完成 \texttt{maxFlow(s,t)} 后调用 \texttt{cutSide(s)}，再检查原有向边的两个端点。

\paragraph{复杂度}
最大流完成后，提取割两侧和筛选割边各需 $O(n+m)$ 时间。

按原输入边提取割边。残量图中的配对反边用于撤销流量，容量含义与输入边不同。

\subsection{最小费用最大流}

最小费用最大流先取得能送出的最大流量，再让该流量的总费用最小。逐次最短增广路算法每轮从残量图选择一条单位费用最小的增广路径。

\begin{itemize}
    \item 反边单价取原边单价的相反数。使用势能 $\pi$ 后，边的约化费用为 $w+\pi[u]-\pi[v]$。
    \item 初始用 Bellman-Ford 建立可行势能。此后用 Dijkstra 求约化距离，再把已到达节点的距离加到原势能。
    \item 按路径瓶颈尽量多推送流量，累计实际单位费用乘增广量，直到流量达到上限或汇点不可达。
\end{itemize}

\texttt{work(s,t,limit)} 返回实际流量和总费用，源汇不同，容量和流量上限均非负。
允许初始负边，要求初始残量网络没有负费用环。检测到负环时返回空值。
势能、约化距离和费用累加使用 \texttt{lll}，返回的总费用须能用 \texttt{ll} 表示。

\cppfile{code/graph/费用流.cpp}

\paragraph{复杂度}
初始化最坏耗时 $O(n(n+m))$。设增广次数为 $A$，单轮耗时 $O((n+m)\log(n+m))$，总空间为 $O(n+m)$。整数容量使 $A$ 至多为实际流量。

要求恰好送出指定流量时，检查返回的实际流量。

\subsection{最小路径覆盖}

DAG 的最小点不交路径覆盖要求以尽量少的有向路径覆盖每个顶点一次，单个顶点也算一条路径。

\begin{itemize}
    \item 把每点拆成左部出点和右部入点。对每条原边 $u\to v$，连左 $u$ 与右 $v$。
    \item 一条匹配边对应把一个路径尾与另一个路径头合并。匹配保证每点最多一个前驱和一个后继，DAG 保证不会合成环。
    \item 最少路径数是 $n$ 减最大匹配数。从没有匹配前驱的点开始沿后继走，可以恢复全部路径。
\end{itemize}

使用原图的边进行连接。若图有环，返回空值。

\cppfile{code/graph/最小路径覆盖.cpp}

\paragraph{复杂度}
采用 DFS 匹配，最坏时间为 $O(n+nm)$，额外空间为 $O(n+m)$。

该构造适用于沿原边连接的点不交路径覆盖。允许路径相交或按可达关系连边时，模型的约束随之改变。

\section{其他图论}

\subsection{欧拉路径、欧拉回路}

欧拉路径恰好经过每条边一次，顶点可以重复。起点和终点相同的欧拉路径是欧拉回路。

\begin{itemize}
    \item 无向图的有边部分连通时，奇度点数为零可成回路，为二可从任一奇度点出发。
    \item 有向图的有边部分忽略方向后应连通。回路要求每点出度等于入度。开放路径要求起点多一条出边、终点多一条入边。
    \item Hierholzer 算法沿未使用的边扩展。当前顶点不存在可扩展的边时，将其追加到逆序序列。遍历结束后反转序列。
\end{itemize}

支持平行边和自环。不存在时返回空值。无边且有顶点时返回只含顶点 $1$ 的路径。
没有顶点时返回空值。

\cppfile{code/graph/欧拉路径.cpp}

\paragraph{复杂度}
每条邻接弧至多被扫描一次，时间和空间均为 $O(n+m)$。

用输出长度 $m+1$ 验证所有边均已访问。

\subsection{基环树}

连通无向图的边数等于点数时，恰有一个环。去掉环上的边后，每棵树都挂在一个环点上。

\begin{itemize}
    \item 反复删除度数为一的点。留下的点恰好是环点。
    \item 按剥叶的逆序处理，每个被删除的点从已确定的邻居继承所属环点，距离加一。
\end{itemize}

要求输入连通的无向图且 $m=n$。\texttt{cycle} 为按点编号列出的环点，\texttt{bel[u]} 是所挂环点，\texttt{dist[u]} 为到环的边数。

\cppfile{code/graph/基环树.cpp}

\paragraph{复杂度}
剥叶和逆序回填都只需扫描邻接表，时间为 $O(n+m)$，额外空间为 $O(n)$。

\subsection{函数图}

函数图中每个点的出度恰为一。反复沿后继前进，最终会进入某个有向环。每个弱连通分量由一个有向环和指向它的若干树组成。

\begin{itemize}
    \item 先用入度为零的队列剥除所有非环点，剩下的点可沿后继逐环编号。
    \item 按剥除的逆序回填，每个点和后继属于同一个环，入环点也相同，到环的距离加一。
    \item 若还要查询走很多步后的点，可配合第一章的倍增模板。
\end{itemize}

后继数组从 $1$ 开始，每项都在 $[1,n]$。环长用 \texttt{cycleLen[bel[u]]} 读取。

\cppfile{code/graph/函数图.cpp}

\paragraph{复杂度}
时间和额外空间均为 $O(n)$。

自环是长度为一的有向环。后继为哨兵的模型需要先约定哨兵的后继。

\subsection{图上贪心}

先定义候选选择和优先顺序，再证明局部选择保持最优解。最小生成树可通过割性质证明选边，退化序着色则通过限制已染色邻居的数量给出颜色数上界。

若选择后候选值会改变，应及时更新维护候选的数据结构。

\subsection{图上状态压缩 DP}

若后续转移取决于已访问的顶点集合，可用掩码表示该集合，并用当前位置等附加信息区分状态。从合法初态出发，沿允许的边更新下一状态。

若每次恰加入一个未访问顶点，则可按掩码递增计算。以掩码和终点构成状态时，状态表占 $O(n2^n)$ 空间，转移时间取决于边数及可达状态数。
